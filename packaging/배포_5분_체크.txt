배포 후 5분 체크 — 기포계수툴 portable

환경: Windows 10/11 · 폴더를 바탕화면에 둔 상태

[ ] 1. 기포계수툴.exe 더블클릭 → 창 제목 "기포 계수 툴" 이 뜬다
       (콘솔 검은 창이 같이 뜨면 실패 — 담당자에게 알림)
[ ] 2. 샘플\스모크_480p.avi (또는 연구실 짧은 클립) 선택
       → 영상 정보 라벨에 해상도·fps가 보인다
[ ] 3. 기본 설정 그대로 시작 → 진행이 끝까지 가고 오류 팝업 없음
[ ] 4. 결과 폴더에 summary.json (또는 결과 열기) 확인
[ ] 5. 멀티웨이 탭이 보이면 탭만 한 번 클릭 (크래시 없으면 OK)
       ※ 전체 12챕터 위저드는 이 체크 범위 밖

실패 시: 같은 폴더 error.log 를 담당자에게 전달
